1. Create src/handlers/groups.ts:
   - Export `registerGroupHandlers(bot: Telegraf)` that registers:

   a) `bot.on('my_chat_member')` -- triggered when bot is added to a group:
      - Check if the bot was added to a group/supergroup (new_chat_member.status === 'member' or 'administrator')
      - Get the chat members using `ctx.telegram.getChatMembersCount` and `ctx.telegram.getChatAdministrators` or iterate known members
      - Identify the owner: look up each member's telegram_id in the owners table. The one who exists is the owner.
      - Identify the cleaner: any group member who is NOT the owner and NOT the bot
      - If no registered owner found in the group, send message to group: "I don't recognize anyone here as a registered owner. The property owner needs to DM me /start first."
      - If owner found but no cleaner yet, store partial group info and wait

   b) When owner and cleaner are both identified:
      - Upsert cleaner into cleaners table (INSERT OR IGNORE on telegram_id)
      - DM the owner: "I've been added to a group with [Cleaner Name]. Which property should I link this group to?\n\n[numbered list of owner's completed properties]\n\nReply with the number."
      - Store a pending_link state (in-memory Map or a pending_group_links table) keyed by owner telegram_id: { chat_id, cleaner_telegram_id, cleaner_name }

   c) Property selection handler (in owner DM):
      - When owner replies with a number in DM and there's a pending group link:
      - Validate the number matches a property
      - Create telegram_groups row: chat_id, property_id, owner_id, cleaner_id, group_type='cleaning', is_active=true
      - Send welcome message to the GROUP chat: "Hi [Cleaner First Name]! I'm TextBud, [Owner First Name]'s cleaning assistant for [Property Name]. I'll guide you through each clean. Text me when you arrive!"
      - Send DM to owner: "Group linked to [Property Name]. [Cleaner Name] is all set!"
      - Clear the pending link state

   d) Handle edge cases:
      - Bot added to group but only 2 members (bot + owner, no cleaner yet): wait for `chat_member` event when cleaner joins later
      - Register `bot.on('chat_member')` to detect when a new member joins an existing bot group -- if the group has no cleaner yet, identify them and trigger the linking flow
      - Owner has no completed properties: DM owner "You don't have any properties set up yet. Send 'new property' to create one first."

2. Update src/bot.ts:

   - Note: the setup handler's DM text listener must NOT intercept property-selection numbers when there's a pending group link. Add a check: if owner has pending group link and message is a number, route to group handler instead of setup handler.
