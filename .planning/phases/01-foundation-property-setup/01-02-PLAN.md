   - Export `registerSetupHandlers(bot: Telegraf)` that registers a text handler on the bot
   - The text handler intercepts ALL DM messages and routes based on setup session state
   - Flow trigger: message text matches /new property/i (case-insensitive) from a registered owner in DM
   - On trigger: create a new Property row (name from next message, setup_step = 'name'), create SetupSession row (current_step = 'name')
   - Session resume: on ANY DM message, check if owner has an active SetupSession. If yes, route to the appropriate step handler. If resuming after absence, send: "Welcome back! You finished [completed steps]. Ready to [current step description]?"
   - Step routing map: 'name' -> ask property name, 'rooms' -> setup-rooms, 'photos' -> setup-photos, 'faq' -> setup-faq, 'checklists' -> setup-checklists, 'deep_clean' -> setup-deepclean, 'review' -> setup-review
   - After receiving property name, update property.name and advance to 'rooms' step
   - Each step handler returns when complete, and the orchestrator advances the session to the next step and calls the next handler's prompt function
   - Helper: `getActiveSession(ownerId: number): SetupSession | null` -- queries setup_sessions for owner with no setup_complete on linked property
   - Helper: `advanceSession(sessionId: number, nextStep: string): void` -- updates current_step and updated_at
   - Helper: `completeSession(sessionId: number, propertyId: number): void` -- marks property.setup_complete = true, deletes setup_session row

   - Confirm: "Got it! I've set up [N] rooms for [Property]:\n1. Kitchen\n2. Master Bedroom\n..." then echo the list
   - Signal completion so orchestrator advances to 'photos'

   - Echo confirmation: "Got it -- staging photo [N] for [Room]. Send more or say 'done' to move to the next room."

   - Create the staging photos directory if it doesn't exist (fs.mkdirSync recursive)
