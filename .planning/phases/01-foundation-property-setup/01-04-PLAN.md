1. Create src/handlers/edit.ts:
   - Export `registerEditHandlers(bot: Telegraf)`
   - This handles conversational editing in DM only

   a) Edit trigger detection (DM messages matching patterns):
      - /edit/i, /change/i, /update/i, /add/i, /remove/i anywhere in the message
      - Only when owner has no active setup session and no pending group link
      - If no active property selected, ask: "Which property do you want to edit?" and show list

   b) Edit routing -- parse the owner's intent from natural language:
      - Keywords to detect edit target:
        - "room" / "rooms" -> room editing
        - "checklist" / "clean" / "task" / "item" -> checklist editing
        - "faq" / "wifi" / "parking" / "trash" / "rules" / "emergency" / "guidebook" -> FAQ editing
        - "photo" / "staging" / "picture" -> staging photo editing
        - "deep clean" / "cycle" -> deep clean cycle editing
        - "name" / "address" -> property name/address editing
      - If intent unclear: "What would you like to edit? You can change:\n- Rooms\n- Checklists\n- FAQ/Guidebook\n- Staging photos\n- Deep clean cycle\n- Property name"

   c) Edit flows (each with before/after confirmation):

      Room editing:
      - "add room": ask room name, INSERT, confirm: "Added [Room] to [Property]. Now has [N] rooms."
      - "remove room": show numbered list, ask which, DELETE room + its staging_photos + checklists + checklist_items (cascade), confirm: "Removed [Room] from [Property]."
      - "rename room": show list, ask which and new name, UPDATE, confirm: "Renamed [Old] to [New]."

      Checklist editing:
      - "add item to [room] [standard/deep] checklist": ask for the item text if not provided, INSERT checklist_item, confirm: "Added '[Item]' to [Room] standard clean. [Room] now has [N] standard items."
      - "remove item from [room] checklist": show items numbered, ask which, DELETE, confirm with updated list
      - "view [room] checklist": show both standard and deep items

      FAQ editing:
      - "update wifi" / "change parking" etc.: ask for new answer, UPDATE faq_entries WHERE category = ?, show before/after: "Updated WiFi info:\nBefore: [old]\nAfter: [new]"
      - "add faq": ask for question then answer, INSERT, confirm
      - "remove faq": show entries numbered, ask which, DELETE, confirm

      Photo editing:
      - "update [room] photos" / "replace [room] staging photos": prompt to send new photos, on each photo replace/add to staging_photos, confirm count
      - "add photo to [room]": receive photo, append to room's staging_photos

      Deep clean cycle:
      - "change deep clean cycle": show current value, ask for new number, UPDATE, confirm: "Deep clean cycle changed from every [old] cleans to every [new] cleans."

      Property name:
      - "rename property" / "change property name": ask for new name, UPDATE, confirm: "Property renamed from [old] to [new]."

   d) All edits show before/after confirmation as specified in CONTEXT.md:
      "Updated Kitchen checklist: added 'Mop the patio'. Kitchen now has 6 items. Here's the full list: [...]"

   e) Track edit state per owner: Map<number, EditState> where EditState = { target: string, subTarget?: string, step: string, data?: any }. Clear after edit completes.

2. Register in bot.ts by importing and calling registerEditHandlers(bot) in the DM router.
