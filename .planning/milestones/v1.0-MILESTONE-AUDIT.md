## Cross-Phase Integration

### Critical: Subscription Gate Blocks New Owner Onboarding

**Location:** `src/bot.ts` lines 126-138

The subscription gate blocks all commands except subscription/billing keywords and "my properties" for unsubscribed owners. "new property" is handled at line 162, but the gate returns early before reaching it. Meanwhile, `handleSubscribe` requires `propertyCount > 0` (payments.ts line 124).

**Impact:** New owners cannot create their first property (gate blocks it) and cannot subscribe (no property exists). Deadlock for first-time users.

**Fix:** Add `/^new property$/i` to the subscription gate allowlist.

### Low: bot.hears Bypass Subscription Gate

Two `bot.hears` handlers fire before the DM text router's subscription gate:
- `reporting.ts:295` — "last report" / "show cleaning"
- `inventory-setup.ts:450` — "setup inventory" / "my inventory"

Unsubscribed owners can access these features. Low severity since the subscription gate is the primary enforcement point and these are read-only operations.

### Low: Orphaned Export and Missing Sync

- `getOwnerSubscription` exported from payments.ts but never imported
- `syncSubscriptionQuantity` not called when properties deleted via manage/edit handlers (only called from setup.ts)
