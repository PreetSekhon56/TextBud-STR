# TextBud STR

SMS/Telegram-based operations assistant for short-term rental (STR) operators. Manages cleaning workflows, photo verification, inventory, and guest support — entirely through messaging.

## Stack
- **Backend**: Node.js / TypeScript
- **Database**: SQLite (better-sqlite3) — scale to Supabase later
- **Messaging**: Telegram (Telegraf)
- **AI**: Claude (conversation + vision for photo comparison)
- **Hosting**: TBD
